# QDeck - Arduino UNO Q Powered Cyberdeck

Welcome to the official repository for **QDeck**—a compact, sleek, and budget-friendly portable cyberdeck powered by the **Arduino® UNO® Q 4GB**. 

This repository houses the raw CAD/STEP files, modular chassis variants, environmental TPU armor options, and software extras (Conky config and wallpaper) to accompany the main build profiles hosted on Makerworld.
